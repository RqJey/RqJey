ПЛАН НАКОВАЛЬНИДобавь книги для расчёта

Здесь появится самый дешёвый порядок операций.

Расчёт для Java Edition: стоимость переноса книги учитывает уровень зачарования и базовую стоимость чар, штраф предыдущих работ учитывается отдельно. Лимит 39 уровней проверяется для каждой операции, а не для суммы всего плана. Ремонт предмета материалами и готовые книги с несколькими чарами не моделируются.
