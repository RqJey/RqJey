Как публиковать изменения

Три простых шага — никакого отдельного сервера.

  1. Один раз создай Fine-grained token для репозитория RqJey/RqJey с разрешением Actions: Read and write.
  2. Вставь токен в поле публикации. Он используется только в текущей открытой вкладке и не сохраняется.
  3. Подготовь новость или изменение и нажми «Опубликовать на сайт». CMS сама запустит GitHub Actions и дождётся результата.
  4. CMS проверит, что данные появились на сайте. При ошибке покажет ссылку на конкретный запуск GitHub Actions.
