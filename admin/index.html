Как публиковать изменения

Три простых шага — никакого отдельного сервера.

  1. Внеси изменения в нужном разделе и нажми «Подготовить публикацию».
  2. Скопируй JSON, открой GitHub Actions и вставь его в поле payload.
  3. Запусти workflow. GitHub создаст Pull Request — проверь его и объедини.
