# RqJey Mods — сайт для GitHub Pages

Статический сайт-каталог Minecraft-модов. Версии и `.jar`-файлы автоматически загружаются из GitHub Releases через публичный GitHub API.

## 1. Настройка

Открой `config.js` и GitHub username уже настроен: `itz_rqjey`.

Проверь `repo` у каждого проекта. Это точное имя репозитория на GitHub, например:

```js
{
  name: "FriendHub",
  repo: "FriendHub"
}
```

Если репозиторий называется иначе, укажи его настоящее имя. Названия из списка сейчас выставлены по твоим скриншотам.

## 2. Как публиковать новые версии модов

Для каждого мода:

1. Открой его репозиторий на GitHub.
2. Перейди в **Releases** → **Draft a new release**.
3. Укажи тег версии, например `1.0.7`.
4. Прикрепи собранный `.jar` в блоке **Attach binaries**.
5. Опубликуй релиз.

Сайт автоматически покажет релиз в списке версий. Если в релизе несколько `.jar`, сайт покажет их все: сначала выбираешь релиз, затем конкретный файл.

## 3. Публикация сайта

1. Создай на GitHub репозиторий с точным названием `ТВОЙ_USERNAME.github.io`.
2. Загрузи в корень репозитория все файлы из этой папки.
3. Открой **Settings → Pages**.
4. В разделе Build and deployment выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, нажми Save.
6. Через некоторое время сайт будет доступен по адресу `https://ТВОЙ_USERNAME.github.io`.

## Важно

- Репозитории с модами и их Releases должны быть публичными, иначе браузер не сможет получить список релизов без авторизации.
- GitHub Pages не принимает файлы через форму на самом сайте. Загрузка сборок выполняется через GitHub Releases.
- Если у репозитория включены ограничения API, сайт покажет сообщение об ошибке.
- Это обычный HTML/CSS/JS — сборка и сервер не нужны.
